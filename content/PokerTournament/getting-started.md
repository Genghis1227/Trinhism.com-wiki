# Getting Started with the Poker Tournament Director

This guide will walk you through launching the dashboard, configuring your first game, and managing the tournament runtime.

## 1. Accessing the Dashboard
Because the Poker Tournament Director is a standalone, client-side web application, you do not need to install any software. Simply navigate to the **Trinhism Labs Poker Suite** and select **Tournament Director** from the menu.

> 💡 **Tip:** We recommend using a modern browser (like Google Chrome, Microsoft Edge, or Firefox) on a laptop or desktop for the best experience. The dashboard is fully responsive, but a larger screen makes managing the ledger and roster easier.

## 2. Configuring the Tournament
Before you start the timer, use the **Settings Sidebar** on the left to prepare your game.

### Financial Configuration
1. **Rake & Costs:** Under the Configuration section, you can optionally configure a percentage or fixed rake taken from the prize pool.
2. **Chips Distribution:** Define the total starting stack size and how the physical chips should be handed out (e.g., 10x $100 chips, 5x $500 chips, etc.).
3. **Payout Structure:** Set how many places pay out (e.g., Top 3) and assign the percentage of the pot each place will receive. The app will automatically validate that your payouts total exactly 100%.

### Blind Schedule
The Blind Schedule dictates the pace of your game.
- Use the **Add to Schedule** button to add new Blind Rounds, Breaks, or Color Up levels.
- You can manually edit the duration (in minutes) and the Small/Big blind values by clicking the inputs directly in the list.

## 3. Managing the Roster
Once the configuration is set up, you can start seating players.

1. Locate the **Roster** section in the main panel.
2. Add a player by typing their name in the input box and pressing Enter.
3. As players pay their buy-in, the **Tournament Pot** automatically updates in the Financials widget based on your configuration.
4. During the game, you can click the action buttons next to a player's name to record **Rebuys**, **Add-ons**, or mark them as **Eliminated**.

## 4. Running the Clock
When players are seated and chips are distributed, you're ready to play!

- Press **Start Game** on the main clock interface.
- To prevent accidental changes, the Settings sidebar will automatically lock when the game starts. (You can unlock it if you urgently need to fix a typo).
- **Audio Alerts:** The application will use Text-To-Speech to announce the new blind levels when the timer runs out. Ensure your device volume is up.

## 5. Theater Mode
For the ultimate home game experience, click the **Theater Mode** button in the top action bar. This will hide the sidebars, maximize the clock and pot sizes, and center the display. Hook your laptop up to a TV to give all players a clear view of the tournament state!
